# Privacidade do Videobot Projeto Dinheiro

O Videobot Projeto Dinheiro é uma ferramenta de uso pessoal para preparar vídeos e enviá-los às contas TikTok que o proprietário autorizar. Não há cadastro público de usuários.

Ao conectar uma conta, o aplicativo recebe do TikTok um identificador da conta, dados básicos de perfil e tokens de autorização. Ele usa esses dados somente para identificar a conta correta e enviar vídeos autorizados. Os arquivos de vídeo e as legendas escolhidos para envio são transmitidos ao TikTok por sua API oficial.

Os tokens ficam em arquivos locais ignorados pelo Git, no computador do operador. O aplicativo não vende dados, não envia tokens a serviços de análise e não publica vídeos sem que o perfil correspondente seja ativado pelo operador. O histórico de envios fica armazenado localmente no projeto.

O proprietário pode revogar o acesso nas configurações do TikTok e apagar os arquivos de token locais. Para dúvidas sobre este projeto, use as [issues do repositório](https://github.com/betaoa/AAAA/issues), sem publicar dados pessoais ou credenciais.
